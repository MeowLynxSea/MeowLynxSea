**[yororen-ui](https://github.com/MeowLynxSea/yororen-ui)** — A reusable Rust UI system built on GPUI, with headless components, swappable renderers, themes, and a declarative XML DSL.

**[yoreni](https://github.com/MeowLynxSea/yoreni)** — An evolving personal-agent runtime exploring persistent identity, memory, event-driven work, and a unified web interface.

Also building:

- **[mai_stock_sim](https://github.com/MeowLynxSea/mai_stock_sim)** — An A-share paper-trading plugin for MaiBot.
- **[Easy Todo](https://github.com/MeowLynxSea/easy_todo)** — A Flutter productivity app, with a [Cloudflare Workers / D1 sync service](https://github.com/MeowLynxSea/easy-todo-sync-worker).
